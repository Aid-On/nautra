# Nautra brand assets

| File | Use |
|---|---|
| `nautra-symbol.png`, `nautra-symbol-dark.png` | The symbol alone, transparent, 1024×1024. |
| `nautra-logo-horizontal.png`, `nautra-logo-horizontal-dark.png` | Symbol and wordmark, transparent. |
| `nautra-cover.png`, `nautra-cover-dark.png` | README header, 1440×606. |
| `nautra-ogp.png` | Social preview, 1280×640. |
| `source/nautra-symbol-source.png` | The original artwork everything else is derived from. |

The `-dark` variants are for dark backgrounds: the deepest purple becomes
off-white so the shell stays readable.

Regenerate everything with `python3 docs/assets/brand/build.py` (needs Pillow).

## Colours

| | Hex |
|---|---|
| Deep | `#3C1AA7` |
| Violet | `#6447F0` |
| Orchid | `#C679FC` |
| Ink (wordmark on light) | `#1E1638` |
| Paper (wordmark on dark) | `#F5F3FC` |
